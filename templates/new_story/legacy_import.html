Migration rules

Device tabs are converted into requests, assets, and outbound/inbound shipments. Duplicate serials already represented in those ledgers are not duplicated from New Inventory.

Incoming Items becomes procurement history. Returned Devices becomes service history. On-site Install becomes installation history. NSS DOMAINS becomes reference data.

Messy historical values are preserved where possible. New records created in the portal use the cleaner database workflow instead of legacy spreadsheet rules.
